# 🌾 Decentralized Traceability and Direct Marketing of Agriculture Supply Chains with QR Scanner

## 📌 Project Overview
This project is a blockchain-based agriculture supply chain management system that improves transparency, traceability, and direct marketing between farmers and buyers. The application allows users to track crop information through QR codes while ensuring secure and tamper-proof records using blockchain technology.

## 🚀 Features

- Farmer/Seller Registration and Login
- Buyer Registration and Login
- Admin Dashboard
- Crop Information Management
- QR Code-based Product Tracking
- Blockchain-based Data Storage
- Direct Buyer-Seller Communication
- Crop Price Management
- Online Payment Module
- Secure Authentication

## 💡 Objectives

- Improve transparency in the agriculture supply chain.
- Eliminate intermediaries between farmers and buyers.
- Provide secure and immutable crop records using blockchain.
- Enable product verification through QR codes.

## 📸 Project Workflow

1. Seller adds crop details.
2. Admin updates crop prices.
3. Buyer views available crops.
4. Buyer sends purchase request.
5. Seller accepts the request.
6. Buyer completes payment.
7. Blockchain stores transaction details.
8. QR Code allows users to verify product information.

## 📁 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/agriculture-blockchain.git
```

2. Navigate to the project folder

```bash
cd agriculture-blockchain
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Start Ganache

5. Deploy Smart Contracts using Truffle

```bash
truffle migrate
```

6. Run the Flask application

```bash
python app.py
```
